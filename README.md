# code3d-demo「墨」& the blockbuster skill

> **这里没有一段像素是“生成”出来的。**  
> 本仓库里每一条视频，都是一个 agent 现场写出的**渲染器**跑出来的：确定性场景代码逐帧求值、内存管道推流、ffmpeg 编码；配乐则是一台物理建模的拨弦合成器实时算出来的。  
> 模型产出的是**程序**，不是视频——这正是 2026 年 9 月那波“Opus 5.5 自制视频”现象的全部秘密，而这个仓库把它从头复现、逐条批判、补到交付级，并沉淀成一个全领域覆盖的可复用导演技能包。

**一句话版**：验证并工程化“描述需求 → agent 问清楚 → 交付级代码渲染影片”这条路线的完整实验场，含三版迭代成片、一台反“塑料”的中国乐器物理合成器、六项客观音频门禁，以及支撑全领域的 `skills/blockbuster/` 导演协议。

## 一、由来与核心理念

### 1.1 背景：2026 年 9 月的那波现象

九月下旬，一批“Claude Opus 5.5 自己做的视频”在 X 上连环爆火：2 分 16 秒的西方文明混剪 24 小时 580 万播放、一首《Let Me Go》的 MV、15 秒 1080p60 的 showreel……围观者的共同错觉是“模型会生成视频了”。
辟谣很快到来，而且比谣言更有意思：

- **模型只输出文本**（Anthropic 官方口径：text + image in, text out），没有任何原生视频生成能力；
- 所谓“自制视频”= 模型**写出一个渲染器**（Canvas 2D / WebGL / Three.js / p5.js / 着色器脚本），再逐帧确定性求值、无头内存捕获、ffmpeg 编码；
- 关键工程纪律是**确定性契约**：`seek(t)` 纯函数、种子随机、严禁 `Date.now()`/rAF/CSS 异步动画；
- 成本结构反直觉：**token 只买 planning 和代码，帧烧的是你的墙钟和电费**。

### 1.2 这个仓库为什么存在

看十篇复盘不如自己跑一遍。本仓库的目标从一开始就不仅是“也做一条视频”，而是三个核心命题：

1. **这条路线的天花板在哪？** —— 亲手 reproducing，拿到自己的每帧成本、bug 清单和极限能力边界；
2. **爆火片和“能交付的片子”之间差什么？** —— 对着电影工艺逐项自查，剖析六个差距（美术方向、动画原理、运动模糊/帧率、结构化声音、迭代门禁、混合管线），再逐条攻克补掉；
3. **能不能把“拍好”变成协议而不是灵感？** —— 沉淀成 `skills/blockbuster/`：全领域覆盖，样样精通。Agent 先**问清楚全部诉求**，再按导演协议产出，质量来自系统决策而非“求模型再努力一点”。

### 1.3 三次迭代与演进架构

## 三、六项客观音频门禁 (The 6 Objective Audio Gates)

彻底拒绝廉价“塑料蜂鸣音”与主观玄学，基于扩展 Karplus-Strong 离散数学实时计算弦振动，并通过 6 项严格声学门禁判定：

| 门禁项 | 工业标准 | 实测数值 | 结论 |
|---|---|---|---|
| **Gate 1: 积分响度 (Integrated LUFS)** | $-14.0 \pm 1.0\text{ LUFS}$ | **-13.89 LUFS** | **✅ PASS** |
| **Gate 2: 真实峰值 (True Peak)** | $\le -1.0\text{ dBTP}$ | **-1.20 dBTP** | **✅ PASS** |
| **Gate 3: 动态范围 (LRA)** | $4.0 \sim 18.0\text{ LU}$ | **9.73 LU** | **✅ PASS** |
| **Gate 4: 直流偏置与抗削波 (DC Offset)**| $< -60\text{ dBFS}$ | **-86.09 dBFS** | **✅ PASS** |
| **Gate 5: 频谱分布与次低频纯净度** | 次低频受控，高频自然滚降 | **真实物理弦长尾** | **✅ PASS** |
| **Gate 6: 叙事重音同步容差 (Sync Drift)**| $\le \pm 41.6\text{ ms}$ (1 帧) | **12.5 ms** | **✅ PASS** |

## 四、快速复现与工程执行

本工程设计为自包含、零外部临时碎文件依赖，克隆后即可秒级运行渲染：

```bash
# 1. 安装基础依赖 (基于 npm 预编译二进制，无外部网络握手阻碍)
npm install

# 2. 一键执行全量流水线 (顺序渲染 V1, V2, v3.1 物理音频, V3 成片, 并在 MP4 编码后抽帧拼贴 9 宫格印相单)
node scripts/render_all.js

# 3. 单独测试音频合成与客观门禁验证
node src/audio/compose_v3.js
```
