# Blockbuster 制作规范（Agent 必读）

目标：做出**讲得清、有信息量、可复现**的讲解/传记类视频。质量的首要标准是内容，技术指标只是门槛。

## 0. 硬性要求（来自用户，违反即返工）
- 配音用标准普通话，**只用 voice-01**。旁白里**不要写希腊字母符号**：μ 写成 "miu"，ε 写成 "epsilon"，其余用英文名。
- 画面必须有**真正的 3D 场景**（建模、运镜、光照），不能只是图片轮播或模板粒子；**必须有逐句字幕**。
- 配乐必须**随画面事件变化**，要有弦乐等多种乐器和氛围音效；**禁止**持续嗡鸣/单音垫底，**禁止**刺耳的转场音效。
- 时效性题材（人物、公司、新闻）必须先搜索，事实截止到今天，并记录来源。
- 需求有歧义时，先用选择题向用户确认。
- 旁白存 FLAC，放在 `examples/<name>/narration/`。交付成片 mp4 以普通 Git 文件放在 `examples/<name>/` 并入库（单文件小于 100 MB，不使用 Git LFS）；渲染临时文件由 `.gitignore` 忽略，中间文件用完就删。
- 不要擅自改仓库公开或私有。不要 force push，不要改写已有历史。推送前说明要推哪些改动、推到哪个分支。

## 1. 流程
| 阶段 | 产出 | 要点 |
|---|---|---|
| Brief | 受众、时长、知识点/叙事线 | 一句话说清"看完能懂什么" |
| 研究 | 事实清单 + 来源 | 数字、日期要能核对；物理和数学内容用真实计算（仿真、训练），不画示意曲线 |
| 脚本 | 6–8 段旁白 + 每段画面设计 | 每段一个视觉主意；数字、公式写成口语读法 |
| 配音 | `narration/sN.flac` | 裁掉首尾静音，必要时 1.1× 变速；**以实测时长为准**建时间线 |
| 场景 | `film.py` | 每段专门设计：模型、运镜、事件时间点锚定到对应的字幕句（`ev(k, i)`） |
| 配乐 | `score.py` | 先写"场景提示表"：每段的情绪、调性、速度、乐器和音效事件，再写代码 |
| 质检 | `python3 -m bb qc` 结果为 0 问题，并**亲自看图** | 见第 3 节 |
| 交付 | 成片 + README（内容、文件、重建方法） | 说明哪些地方没有验证过 |

## 2. 场景设计准则
- **信息优先**：画面要讲当前这句话，比如数字用计数器或柱体，地点用地球加弧线，时间用飞越式时间轴，关系用 3D 图谱。
- **镜头**：每段都有缓慢的轨道运镜或推拉；段落之间用 0.3–0.4 s 淡入淡出，不需要转场音效。
- **精细度**：城市、机器这类场景要有层次（路网、街区、窗灯、地标、载具朝向、灯光）。粗糙的方块会被用户直接指出来。
- **文字**：大标题和数字放左上，章节放右上，字幕放底部；3D 标签交给引擎自动收进画面并避让。单条字幕 ≤ 22 字左右，字速 ≤ 7 字/秒。
- **真人**：不画真人肖像；AI 生成图只能做点缀，而且要标注"AI 生成示意画面"。

## 3. 质检（内容 > 参数）
1. `bb qc` 自动检查：缺字形、文字出画、文字重叠、字幕过长/过短/过快、响度 −14±1 LUFS、峰值 ≤ −1 dBFS。
2. **看接触单和每段关键帧**：检查穿模、镜头穿过物体、时间线错位（镜头比字幕快或慢）、画面是否对应当前这句话。
3. 抽查几个事件点的声画对齐：爆炸、落地、计数到头、重音。
4. 交付时如实写明哪些地方没有验证过（比如没法试听）。

## 4. 已知的坑
- Noto CJK 缺字形：`✕ ⚠ ₃ ⁺ ⁻` 等（`✓` 和 `²` 有）。`bb qc` 会报出来。
- 画家算法：地面、道路、湖面这类大平面必须单独放一层（`f.layer()`）先画，否则会盖住建筑。
- `read_file` 读同名图片可能返回旧缓存：每次换新文件名（`bb still` 已自动加后缀）。
- 字体和 ffmpeg 不要写死家目录。字体用系统的 Noto Sans CJK，或 `BB_FONT_DIR`。ffmpeg 用 PATH、`BB_FFMPEG`，或 `bb.media.ffmpeg()`。环境自检：`source tools/ensure_ff.sh`。
- 旧版 ffmpeg 不要用单遍 loudnorm，会漂移或截断：改用固定增益 + `alimiter`（`bb remux` 已处理）。AAC 编码后峰值会过冲约 0.2 dB，所以限幅设在 0.8。
- 机器只有 2 核、1 GB 内存：渲染用 `--jobs 2`，不要在内存里整片缓存帧。
