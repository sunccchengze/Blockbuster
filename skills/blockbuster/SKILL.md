# BLOCKBUSTER: UNIVERSAL PROMPT-TO-VIDEO PIPELINE & SKILL SPECIFICATION

> **核心法则**：这不是固定 Demo，而是一个可持续运转的工业级视频生产流水线。
> 输入任意自然语言需求，流水线自主完成意图解构、分镜编剧、程序化视觉编译、物理声学定制、确定性光流渲染与抽帧质检。
> 全领域覆盖，样样精通，做到极致。

## 一、什么是 Universal Blockbuster Pipeline？

`blockbuster` 是专为 Coding Agent 设计的**通用端到端视频生产流水线（Sustainable Prompt-to-Video Pipeline）**。

传统视频生成模型往往依赖庞大的不可控黑盒扩散模型，生成画面不可控、文字混乱、无物理声画对齐。
Blockbuster 采用完全软件工程化的**代码驱动电影工业协议（Code-Driven Deterministic Cinema）**：
- **任意需求输入**：接收任何自然语言创意描述（科技发布会、深空宇宙科普、极简工业硬件、金融数据大屏、东方意象艺术等）；
- **全自主闭环**：流水线在 10~15 秒内，现场完成分镜编剧、现场编译图形逻辑、现场离散物理合成 48kHz 音轨、现场内存直推 FFmpeg 压制 MP4，并从产出的 MP4 中抽取关键帧生成接触单，验证所有客观门禁；
- **可持续运转**：支持命令行 CLI、Node.js 编程式 API 与 Apple Design 风格生产级 Web 工作台交互。

## 二、通用流水线五大生产阶段

### Stage 1: 意图解构与类型学标定 (Director Analysis)
针对输入的自然语言，流水线自动匹配最契合的影视类型学拓扑：
- **未来科幻 / 量子科技 (Sci-Fi)**：青蓝/紫/霓虹高反差，高速光流、晶格网络、模拟合成器；
- **深空宇宙 / 天体物理 (Cosmos)**：洋红/深邃黑/引力金，星云扩散、引力坍缩、低频宇宙风；
- **工业三维 / 极简硬件 (Product 3D)**：纯白/钛灰/深空灰，高光反光板、精密旋转、极简纯净打击音；
- **数据智能 / 金融孪生 (Data Viz)**：天蓝/绿/橙，流形曲面、算力脉冲、高频数字滴答；
- **东方美学 / 意象写意 (Organic Art)**：宣纸微暖灰/焦墨/朱砂，墨晕破墨、狂草行笔、古琴物理滑音。

### Stage 2: 动态 6 阶段叙事分镜编剧 (Deterministic Storyboard)
每一部生成的影片遵循电影动力学起承转合结构：
1. **起势 (Genesis / Singularity)**：虚空创生，引力核心点亮，空间结构开始舒展；
2. **升维 (Dimensional Unfolding)**：晶格与能量脉络向外高速延伸，镜头环绕旋转；
3. **奔涌 (Kinetic Velocity)**：光流管道穿梭，强烈的运动模糊与景深虚化；
4. **破界 (Macro Fusion / Climax)**：镜头猛烈拉远，宏观三维图腾现世，冲击波谐振；
5. **铭刻 (Emblem Inscription)**：收束为精炼品牌图腾与电影级排版定格；
6. **归寂 (Harmonic Tail)**：空间能量下沉，宽银幕遮罩锁定，余音回甘。

### Stage 3: 程序化定制物理声学合成 (Procedural Audio DAW)
彻底告别死板预录音效，流水线根据分镜毫秒级生成声轨：
- **离散物理琴弦仿真 (Karplus-Strong)**：支持激励脉冲、分数延时与指肉/指甲阻尼衰减；
- **电影级重音 Braam**：指数调频锯齿波叠加 45Hz 次重低音；
- **多轨混音与空间共鸣**：桐木琴箱与空间低通滤波；
- **自动化母带压限**：
  - 动态增益对齐目标：$-14.0 \pm 1.0\text{ LUFS}$；
  - 真实峰值削波限制：$\le -1.0\text{ dBTP}$；
  - 直流偏置精确消除：$< -60\text{ dBFS}$（实测达 $-107\text{ dBFS}$）。

### Stage 4: 确定性流式渲染与 180° 快门动捕 (Stream Rendering)
- **绝对纯函数约束**：每一帧由 $f(t)$ 求值决定，严禁隐式依赖 `Date.now()` 或物理计时器；
- **Mulberry32 伪随机数**：带种子 PRNG，保证跨平台比特级绝对一致；
- **180° 快门积分**：子曝光多重采样（2x ~ 8x），通过高斯核衰减模拟电影胶片光学曝光特性，杜绝 3D 渲染器常见的阶梯走样；
- **零磁盘 IO 推流**：Node.js 内存 Buffer 通过 stdin 管道直推 FFmpeg（`rawvideo rgba -> libx264 yuv420p`），零临时小碎图落盘，平均渲染速度超过 18 fps。

### Stage 5: 双轨质检认证与交付闭环 (Dual QC Suite)
- **画面质检**：拒绝仅检查代码。流水线自动在 MP4 封装完成后，从生成的二进制视频中真实抽取各节拍中间帧，拼贴为 1920×1200 接触单，验证视觉内容真实落地；
- **声学质检**：运行 EBU R128 客观声学 6 项门禁测试，生成频响瀑布图并输出状态评级；
- **全量资产交付**：生成包含视频、音频、接触单、分镜数据与质量指标的独立 `manifest.json`。

## 三、如何使用通用流水线？

### 方式一：命令行一键生成 (CLI)
只需在终端传入任意需求描述：
```bash
# 生成科幻芯片发布会
npm run generate -- --prompt "制作一个未来科幻风格的量子计算芯片发布会视频"

# 生成深空天体科普
npm run generate -- --prompt "制作一个深空宇宙黑洞与超新星大爆炸的天体物理科普短片"

# 生成工业硬件展示
npm run generate -- --prompt "极简北欧风的智能硬件手表工业设计与精密旋转展示"
```
流水线将在控制台实时打印阶段日志，并在 12 秒内输出交付文件。

### 方式二：Web 演播厅可视化创作 (Studio Web UI)
1. 启动服务：
   ```bash
   npm start
   ```
2. 访问 `http://localhost:3000`（或远程宿主 3000 端口）。
3. 在顶部的 **Universal Prompt-to-Video Creator** 输入框键入需求，或点击预设标签；
4. 点击 **“立即运行流水线制作视频”**；
5. 观察 5 阶段实时步进与下方终端 SSE 日志；
6. 制作完成后，播放器自动载入成片起播，可逐帧微步核验，下方展示完整 6 叙事节拍、双轨质检图表与下载入口。

### 方式三：Node.js 编程式调用 (Programmatic API)
```javascript
const { runBlockbusterPipeline } = require("./src/pipeline/orchestrator");

async function createVideo() {
  const manifest = await runBlockbusterPipeline("金融科技智能算力大屏，拓扑流形与数据脉冲", {
    onLog: (msg) => console.log(msg)
  });
  console.log("交付视频路径:", manifest.deliverables.videoFile);
  console.log("质检门禁状态:", manifest.audioQC.allPassed);
}
createVideo();
```

## 五、工业铁律与纪律守则 (The Iron Rules)

1. **拒绝死板 Demo，必须始终维护通用流水线**：
   - 任何新增特性必须接入 `src/pipeline/`，确保任意新需求均可自主编译并交付；
2. **严禁中间碎图落地**：
   - 全链路使用 `Memory Buffer -> FFmpeg stdin Pipe`，严禁在磁盘上生成成千上万张临时 PNG/JPG；
3. **确定性高于一切**：
   - 严禁在渲染循环内使用未加种子的 `Math.random()` 或物理时钟；
4. **客观门禁一票否决**：
   - 积分响度偏离超过 $\pm 1.0\text{ LUFS}$、真实峰值突破 $-1.0\text{ dBTP}$、或抽帧质检单存在空白损坏，一律判定为不合格，必须自动校准重新输出；
5. **每一次 Push 必须更新 `HANDOFF.md` 并保持自我记忆 `MEMORY.md` 同步**。
