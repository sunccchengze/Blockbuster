# STORYBOARD — `code3d` (12.0s / 360 frames / 1280×720 @ 30fps)

一条自我说明的片子：内容就是它自己的生成方式。
单镜头连续运镜，不切镜——运镜本身就是 3D 的证据。

## 全局规则

- **确定性**：每个像素只是 `t` 的函数。禁用 `Date.now()` / `requestAnimationFrame` /
  CSS transition / timer；粒子位置来自 seeded PRNG（`mulberry32(20260922)`）。
- **一个时钟**：音轨 120 BPM（beat = 0.5s），四张字卡全部落在 beat 上，
  画面闪白也按同一个 beat 公式算 —— 音画同步不是后期对齐的，是同源的。
- **文字用 CanvasTexture**：这是代码渲染相对扩散模型的最大优势，必须展示出来。
  字体 `Noto Sans CJK SC`，像素级锐利，零乱码。

## 分镜

| # | 时间 | 画面 | 字卡 | 运镜 |
|---|---|---|---|---|
| 1 | 0.0–3.0 | 全黑。网格地面从中心向外亮起，一道脉冲环扩散 | `f(t)` / 每一帧都是时间 t 的纯函数 | 机位低而远，直线推近 |
| 2 | 3.0–6.0 | 镀铬环面结（torus knot）出现并自转，1100 个实例化八面体绕它分布 | `three.js + WebGL` / 几何、材质、光照、镜头，全是代码 | 向右弧线绕行 ~180° |
| 3 | 6.0–9.0 | 机位拉起后退，露出整个螺旋粒子场的全貌 | `360 frames @ 30fps` / 无头浏览器逐帧 seek(t) → 截图 | 升 + 后拉，俯瞰 |
| 4 | 9.0–12.0 | 环境压暗，主体前推发光，收在字卡上 | `ffmpeg → MP4` / 帧序列 + 代码合成的音轨 | 俯冲回到正面，停稳 |

## 运镜实现

不写死关键帧，用 `CatmullRomCurve3` 定义 9 个控制点的路径，再用一张
**时间 → 路径进度** 的分段 smoothstep 映射，让每个 beat 处速度归零（镜头"落定"）：

```
t=0 → u=0.00    t=3 → u=0.20    t=6 → u=0.50    t=9 → u=0.75    t=12 → u=1.00
```

叠加一组固定频率正弦做微幅手持漂移（0.02 单位）——确定性，但画面不死板。

## HUD

左下角常驻读数：`t = X.XXX s` / `frame NNN / 360` / `1280×720 · 30 fps · SwiftShader`，
