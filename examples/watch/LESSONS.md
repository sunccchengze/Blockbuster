# 上限之作复盘：10 秒飞行陀飞轮（Blender Cycles · 全程序化 · 一镜到底）

> 这是原工作区复盘，保留供追溯。当前工程在 `examples/watch/`，重建方法见 [README](README.md)。文中的旧家目录、容量判断和 `sleep` 等操作不是当前环境的使用指令；长任务使用后台进程工具，帧与大型依赖不入 Git。

> 写给后来者：在一个只有 **2 核 CPU、1 GB 内存、无 GPU、工作区 128 MB** 的沙盒里，
> 如何做出接近商业广告质感的 3D 短片。代码都在本目录：`scene.py`（建模+材质+灯光+运镜）、
> `score.py`（配乐）、`assemble.py`（片尾字幕+编码）。

---

## 一、最关键的决定：换引擎，而不是在旧引擎上堆细节

- 之前的视频用自写的 numpy 渲染器（画家算法 + 平面着色）。它的天花板是“干净的示意图”，
  再怎么加零件也不会有金属反射、折射、景深。**质感的上限由渲染方式决定，不由模型数量决定。**
- 用户说“全部能力发挥出来”时，第一步就应该问：**这个环境里能不能跑真正的路径追踪？**
  答案是能：Blender 官方便携版无需安装，下载解压即可后台运行。

### 在沙盒里跑 Blender 的步骤
```bash
mkdir -p ~/.cache/bl && cd ~/.cache/bl
curl -sL https://download.blender.org/release/Blender4.2/blender-4.2.3-linux-x64.tar.xz | tar xJ
sudo apt-get install -y libxkbcommon0          # 唯一缺的系统库
~/.cache/bl/blender-4.2.3-linux-x64/blender -b --factory-startup -P scene.py -- still 1
```
- 放在 `~/.cache`：不计入工作区快照（Blender 本体约 1 GB）。代价是**沙盒重置后需重装**（30 秒）。
- 没有 GPU → 只能用 **Cycles CPU**（EEVEE 需要 OpenGL，不可用）。

## 二、选题：选“精细建模天然好看”的东西

机械表机芯几乎是为展示渲染能力而生的：
- **材质丰富**：拉丝金、玫瑰金、镜面钢、烧蓝螺丝、红宝石（透射/折射）、日内瓦波纹。
- **可程序化**：齿轮、螺线、圆环、桥板都能用数学精确生成，代码量可控。
- **自带动画逻辑**：齿轮按齿数比联动、摆轮振荡、擒纵轮一跳一停——动起来就“像真的”。
- **微距友好**：小物体 + 浅景深 = 立刻有电影感。

## 三、建模技巧（全部见 `scene.py`）

| 部件 | 做法 | 要点 |
|---|---|---|
| 齿轮 | 每个齿 10 个轮廓点（齿根/齿腹/齿顶）→ 与内圈等点数桥接 → 挤出 | 真实模数：齿顶 = r + m，齿根 = r − 1.25m |
| 辐条 | 渐细四边形独立挤出 | 与轮缘/轮毂允许重叠（渲染上看不出） |
| 啮合 | 中心距 = r1 + r2；角速度 w2 = −w1·n1/n2 | 轮系转速真实联动，观众下意识觉得“对” |
| 游丝 | 阿基米德螺线 1400 点 POLY 曲线 + bevel_depth | 14 圈，随摆轮反向微转 + 缩放“呼吸” |
| 红宝石轴承 | 旋转体轮廓（带油池凹面）+ 金套 + 钢轴尖 | IOR 1.77、Transmission 1 |
| 烧蓝螺丝 | 两个半圆顶，中间留一字槽 | 小细节在特写里极其加分 |
| 桥板 | 折线 → 法线偏移成带状 → 两端半圆封头 | 玫瑰金 + 倒角 |
| 所有边 | **Bevel 修改器（0.003–0.01，2 段）** | **最重要的一个技巧**：倒角让每条边都有一道高光，“CG 感”立刻消失 |

材质要点：
- 金属：`Metallic=1`，粗糙度 0.06–0.25；**径向各向异性**（Tangent 节点 RADIAL）模拟车削拉丝。
- 粗糙度叠加高频噪声（±30%），避免“塑料般均匀”。
- 日内瓦波纹：Wave 纹理（BANDS + SAW）同时驱动凹凸和粗糙度。

## 四、灯光与曝光

- 世界光用 Blender 自带的 `studiolights/world/interior.exr`（无需联网找 HDRI），
  **只给反射用**：用 Light Path 的 *Is Camera Ray* 把镜头直接看到的背景换成近黑色。
- 主光（大面光暖色）+ 轮廓光（冷色细长条）+ 顶光 + 一条窄长条光（给齿轮拉出长高光）。
- **第一版严重过曝**（金属反射了整张环境图）：环境强度 0.55 → 0.12，主光 900 → 220，
  夹板底色 0.78 → 0.34。**金属物体要暗环境 + 少量强光源，才会有黑白分明的反差。**
- 色彩管理用 AgX + Medium High Contrast。

## 五、运镜：一镜到底的设计与“防穿模”

- 摄影机 + 注视点（Track To）+ 焦点物体（DOF focus_object）+ 滚转空物体，四者同步关键帧，
  Bezier + AUTO_CLAMPED 插值保证顺滑。每个关键帧同时设置**焦距（40–100mm）和光圈（f/1.4–6）**，
  得到“推拉变焦 + 焦点转移 + 景深由浅到深”的复合运镜。
- 镜头语言顺序：微距细节 → 焦点转移 → 环绕（荷兰角）→ 飞越 → 低空掠过 → 俯瞰 → 拉远全景 + 标题。
  **从极近到全景的“揭示”是最有冲击力的结构。**
- **最大坑：镜头穿进零件。** 关键帧本身没问题，但 Bezier 插值的中间路径会擦过框架/螺丝，
  画面变成一团模糊。解决方法：
  1. 定规则：镜头离陀飞轮中心 > 0.65、在轮系上方时 z ≥ 0.4、贴面低掠时从表壳**外面**进入；
  2. 发现问题就**加中间关键帧**把路径抬高，而不是只改端点；
  3. 允许保留个别短暂的前景虚化扫过（约 0.5 秒），它可以充当“转场”。

### 低成本预览（必须做）
```bash
SAMPLES=4 PCT=25 SDIR=/tmp/pv/ blender -b --factory-startup -P scene.py -- still $(seq 1 11 250)
```
25% 分辨率 + 4 采样，**23 帧约 45 秒**，拼成接触表一眼看完整条运镜。改了三轮才定稿。
**正式渲染前不做全路径预览 = 浪费几个小时。**

## 六、渲染预算（2 核 CPU 的现实）

| 设置 | 单帧时间 |
|---|---|
| 初始（16 采样、8 次反弹、512 瓦片） | 110 s |
| 降反弹（5/3/4）+ 持久数据 + 光源树 + 大瓦片，10 采样 | 40 s（全景）/ 60 s（微距） |
| 最终：8 采样 + OIDN 降噪 | 平均约 56 s → 250 帧 ≈ 4 小时 |

- 时间 ≈ 固定开销约 15 s + 每采样约 5 s；**降噪器（OpenImageDenoise）让 8 采样可用**。
- 微距帧（大光圈景深 + 红宝石透射）最慢；关闭焦散、限制间接光钳制（clamp 6）防萤火虫噪点。
- 运动模糊（快门 0.45）保留——它是“电影感”的重要来源。

### 断点续渲（血泪教训）
第一次渲染输出到 `~/.cache`，沙盒中途重置 → **帧全部丢失**。改为：
- 每帧渲染为 **JPEG 质量 96（约 150 KB）**，直接写进工作区 `watch/frames/`（250 帧 ≈ 37 MB，可被快照保存）；
- 先写 `.tmp.jpg` 再原子重命名，**已存在的帧自动跳过**，随时可以中断续跑；
- 长等待用 `sleep 1740`（工具上限 1800 s），避免数百次轮询。

## 七、声音：让画面“有心跳”

- 擒纵声 tick/tock **与画面的 4 拍/秒严格对齐**（擒纵轮每 0.25 s 跳一格），这是同步感的来源。
- 大提琴断奏同速（8 分音符 = 0.25 s），弦乐 Dm → B♭ → Gm → A 逐段渐强渐亮。
- 每次甩镜在关键帧前 0.35 s 放 whoosh；拉远揭示时 riser → 定音鼓 + 低频 boom + D 大调和弦 + 钟琴琶音。

## 八、工作区与交付

- 工作区上限 128 MB：**一旦超出，整个会话的文件都不保存**（这次就因此让用户一度看不到成片）。
  交付前务必 `du -sh --exclude=.cache ~`，删掉帧序列、截图、混音等中间文件。
- 片尾字幕用 PIL 叠加在帧上（字距从宽收紧的淡入），ffmpeg `libx264 -crf 14 -preset slow` 编码，
  再用 `~/remux.sh` 混音并做响度标准化。

## 九、可复用的检查清单

1. 先问：这个环境能跑的**最高级渲染方式**是什么？（路径追踪 > 光栅化 > 画家算法）
2. 选材质丰富、可程序化、能动起来的题材。
3. 所有硬边加倒角；金属加各向异性和粗糙度噪声。
4. 暗环境 + 少量强光；先渲一帧检查曝光。
5. 一镜到底：微距 → 揭示；焦距、光圈、焦点、滚转一起做关键帧。
6. 全路径低清接触表预览，修掉穿模，再正式渲染。
7. 估算 `单帧时间 × 帧数`，用采样数 + 降噪器控制在可接受范围。
8. 帧写入持久目录、可断点续渲。
9. 声音与画面节奏严格同步。
10. 交付前清理工作区，确认文件真的保存下来了。

## 十、还可以更进一步（时间/算力允许时）

- 更高采样（32+）消除降噪带来的细节涂抹；1080p 输出。
- 蓝宝石表镜（薄玻璃）+ 表盘反光；体积光束（极淡雾）。
- 机芯背面的 perlage（珍珠纹）、齿轮的倒角抛光边（anglage）做成单独的高光材质。
- 用几何节点替代 Python 循环，建模更快、可做更多零件。
