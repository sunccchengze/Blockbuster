# 经验总结

> 这是 2026-09-30 做浓差电池时的记录。当时的路径（`~/bin`、同级 `Blockbuster/`、`music.js`）已经过时。
> 现在的重建方法见本目录 README。一键模板流水线已废弃，不要恢复。

## 流程
1. **先问清诉求再动手**：观众层级、配音/字幕、视觉风格用选择题一次问完，后续几乎无返工。
2. **用户说“已改公开”就立刻重试**：第一次 fetch 404 后没有主动复查，被用户指出。外部资源状态可能随时变化，用户给出新信息时应立即重新获取。
3. **Blockbuster 的一键生成器只有固定流派模板（8 秒抽象视觉），不适合知识讲解**。正确用法是遵循其协议（纯函数 f(t)、种子 PRNG、内存直推 FFmpeg、成片抽帧质检），针对题材手写场景。
4. **先定音频、再定画面**：先生成旁白、实测每段时长，再把所有动画时间码绑定到实测时长上，声画天然对齐。总时长超了就精简文案 + 轻度变速（≤1.2×），不要硬压画面。
5. **每次改动都抽静帧/接触单自查**：首轮静帧就发现上下标字形缺失（豆腐块）、电压表数字溢出、公式面板越界。

## 技术坑
- **Noto CJK 缺 ²⁺ ⁻ ₃ 等上下标字形** → 写 `fillRich()`，把上下标字符转为缩小并偏移的普通字符绘制。
- **旧版 ffmpeg**：`amix` 无 `normalize`（用 `volume` 补偿）；`sidechaincompress` 需 `aformat` 统一两路格式；侧链输入短于音乐时会把尾巴截掉，需要先 `apad`。
- **单遍 loudnorm 会漂移且可能截短**，改为固定增益 + `alimiter` 更可控。
- **沙箱里 `node_modules` 和 pip 包可能不跨轮保留**。现在用仓库根的 `.venv` 和 `npm install`，不要再链到 `~/bin`。
- 快门模糊用 2 子帧足够，60 秒 1450 帧约 2 分钟渲染完。

## 审美与内容
- **配乐**：持续的低八度正弦 = “嗡嗡声”；和弦间线性滑频 = 怪异音效。教学片宜用有节奏但克制的分解和弦，并对旁白做侧链闪避。
- **颜色可读性**：深色背景上的黑色导线不可见；且电学惯例正极红、负极黑/绿——首版把负极标成了红色，属于错误。
- **公式表述**：用户认为 ln 应为 lg。两者都对（RT/nF 配 ln；0.0592 V/n 配 lg）。处理方式：不简单改成用户说的样子，也不硬顶，而是同时给出两种形式和换算，既科学又符合国内教材习惯。
