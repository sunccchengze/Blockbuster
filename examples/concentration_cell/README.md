### 数值说明

恢复的是原项目的科学说明，不是一次新的实验核验。备份记录：活度系数取 CRC 手册 CuSO₄ 平均离子活度系数表（25 ℃、质量摩尔浓度）；以 γ± 近似代替单个 Cu²⁺ 的活度系数，单离子活度不可独立测量。因此约 0.03 V 是量级估算，不含液接电势，不能标成已验证的实测值。

原字幕 / 旁白说明 s5 仍写“实测大约只有 0.03 伏”，画面沿用备份中的近似说明；重新交付前应核对来源并重录措辞，不能仅凭恢复成功就宣称科学审校完成。

## 重建

在仓库根目录安装 Python 依赖、中文字体和 `npm ci` 后：

```bash
bash examples/concentration_cell/build.sh
```

只换音轨（旧 60.4 秒视频不能直接匹配 v4 旁白）：

```bash
python3 examples/concentration_cell/score.py
python3 -m bb remux 已按新版时间线渲染的成片.mp4 examples/concentration_cell/mix.wav
```
